# 地图、分层演出与剧情漫画交接

## 当前版本

保留上游 `5c61364` 的音乐、音效、音量设置及波次调试功能。更新边境要塞、圣林加护、亡者之门底图、路点、建造位置和选关预览；场景包含美术接入后手动调整的塔位和路径，请以本次正式场景为准，不要使用旧候选或一次性安装脚本重建覆盖。

亡者之门使用新版 Boss 斗篷和法杖光束、椭圆旋涡及封印动画。门框 3 个符文、祭坛 4 个石柱符文及 1 组地面法阵独立显示。主门用于剧情演出，第 3、5、7 波在左右道路出现临时传送门；原增援数量拆到左右路，其他波次的增援由正常入口进入。

四个可玩关卡各有入场、胜利漫画。入场阅读阻止建造与出兵；圣林和亡者之门在原有加护/封印演出完成后才显示胜利漫画，失败不会触发。漫画界面使用纸质边框，详见 `StoryComics.md`。

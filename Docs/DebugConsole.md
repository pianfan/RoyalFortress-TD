# 波次调试台

在任意可玩关卡内按 **Esc → 调试台**。输入目标波次或使用 − / + 调整，查看预计补发金币，再点击「跳转并开始」。跳转从目标波次开头重新出怪，并自动退出暂停。

## 跳转规则

- 保留已建防御塔、当前金币和基地生命。
- 停止当前出怪，清除旧敌人、投射物与天气，重新初始化塔的攻击状态。
- 前 N−1 波按全部击杀的奖励补齐；已经实际获得或由调试台补过的部分不重复发放。
- 奖励读取当前关卡的实际波次配置，兼容普通计数和分组出怪，并包含兽人、特殊怪与 Boss。
- 可以向前或向后跳转。回跳不扣回已得金币，但本局每波累计发放的击杀/补发金币不超过其配置总奖励，不能靠反复回跳重复领取整波金币。
- 新进入关卡或重新开始会重置奖励记录。
- 目标必须在 1 到关卡总波数之间。基地生命为零时需要先重新开始。

圣林加护同步此前已完成波次的仪式进度和脉冲储备；亡者之门同步推进进度。即使通关后回跳，也会重置结局演出、恢复建造与攻击。历史实际击败/漏怪计数保留，不把跳过的怪物计为真实击败。

调试台内按 Esc 或点击「返回设置」回到暂停菜单，再按 Esc 可继续游戏。

## 示例

翡翠回廊从开局跳到第 5 波：前四波奖励合计 834 金币。如果已击杀获得 18 金币，本次补发 816 金币。若已购买一座 90 金币箭塔，跳转后金币为 `380 − 90 + 834 = 1124`，箭塔继续保留。

# 快速开始

RoyalFortress TD 是一款 2D 奇幻塔防游戏。用金币在道路旁建造防御塔，击败来袭敌人，保护基地直到全部波次结束。

## 打开工程

1. 下载或克隆仓库，用 Unity Hub 添加包含 `Assets`、`Packages`、`ProjectSettings` 的工程根目录。
2. 使用 **Unity 6000.3.27f1** 打开，等待依赖安装与资源导入。
3. 在 Project 面板找到并双击 `Assets/Scenes/MainMenu.unity`。
4. 点击编辑器顶部的 Play，再点击 Game 画面，使其获得键盘焦点。

首次导入会生成本地 Library 缓存。运行中所做的建造和场景变化不会保存为关卡初始状态。

## 开始一局

首页点击「开始游戏」，选择地图后进入战场：

- **边境要塞**：300 初始金币、7 个塔位、3 波敌人，第三波开放墓穴支路。
- **圣林加护**：300 初始金币、10 个塔位、8 波敌人，守护祭坛并完成加护仪式；通关永久解锁火球、攻速强化。
- **亡者之门**：300 初始金币、10 个塔位、7 波敌人，守住防线并封印传送门。
- **翡翠回廊**：380 初始金币、12 个塔位、5 波敌人，最终波出现灾厄巫师。

从底部拖动塔卡到空石台，松手购买建造。绿色预览表示可放置；金币不足、石台已占用或松手位置无效时不能建造。右键可取消拖动。

点击已经建好的塔，才会在塔旁显示出售选项；点击「出售」返还实际建造价的 70%（向下取整），坑位可重新建塔。箭塔、冰霜塔、法师塔、投石塔默认分别返还 63、77、98、112 金币。点击空白地图、右键、Esc 或「取消」只关闭面板。拖图不会打开出售选项；暂停、剧情和胜负结算期间不能出售。

布置好后，点击「开始第 1 波」。防御塔会自动攻击，击杀敌人获得金币。准备阶段和战斗期间均可继续建塔，当前波结束后再手动开启下一波。

## 观察战场

- 顶部状态条显示金币、基地生命和波次。
- 点击顶部「速度」按钮，依次切换 1×、2×、3×，加速出怪、移动、攻击、天气和技能持续时间；镜头操作与界面保持原速度。暂停后继续保留所选速度；重开、换图、返回首页及胜负结算恢复 1×。
- 鼠标滚轮缩放，按住左键拖动地图，WASD 或方向键也可平移视野。
- Home 或右下角「复位」恢复初始视野；概览状态下，地图边界会限制平移，可先放大再拖动。
- 灾厄巫师出现时，上方显示 Boss 血条、天气效果与倒计时。暴雪降低攻击塔攻速，沙尘暴提高全体怪物移速。

## 暂停与结束

按 Esc 或点击右上角「菜单 Esc」打开暂停菜单。游戏会停止战斗、出怪及天气倒计时，同时取消拖塔并暂停地图操作。
首页和暂停菜单中可分别调整音乐、音效音量；设置会自动保存，拉到 0 可静音。

- 「继续游戏」或再次按 Esc：恢复当前战斗。
- 「重新开始」：重置当前关卡的生命、金币、波次和已建防御塔。
- 「返回地图选择」：返回地图列表，并选中刚才游玩的地图。
- 「调试台」：输入目标波次，预览补发金币，再跳转开始；已有防御塔和当前生命保留。

消灭全部波次获胜，基地生命归零失败。退出编辑器运行模式请再次点击 Play。

更多玩法见 [游戏介绍](../README.md)，关卡说明见 [地图与开始界面](MapsAndMenu.md)。

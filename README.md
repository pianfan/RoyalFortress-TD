# RoyalFortress TD · 王国边境塔防

使用 Unity 制作的 2D 奇幻塔防游戏。用金币部署防御塔，击败来袭敌人，守住基地直到全部波次结束。

![王国边境塔防](Assets/Art/Menu/royal-fortress-title-v1.png)

## 游戏内容

- **四张地图**：边境要塞、圣林加护、亡者之门、翡翠回廊，可在首页自由选择。
- **四种防御塔**：箭塔单体射击、冰霜塔持续减速、法师塔穿甲、投石塔范围攻击。拖卡购买建造，击杀赚取金币；出售返还实际建造价的 70%。
- **通关解锁技能**：完成圣林加护后永久解锁火球和全塔攻速强化，每关共享 3 次使用机会，消耗金币并共用冷却。火球带有飞行拖尾与爆炸特效。
- **天气 Boss**：翡翠回廊最终波出现灾厄巫师，暴雪降低塔的攻速，沙尘暴加快怪物移动。
- **战场操作**：地图缩放与拖动、可收起的塔/技能共用栏、随波次变化的入口箭头，以及 1× / 2× / 3× 加速。
- **声音与设置**：背景音乐、战斗音效、独立音量调节；暂停菜单提供重开、选关和波次调试台。

## 基本操作

| 操作 | 功能 |
| --- | --- |
| 拖塔卡到空石台并松手 | 购买建塔，右键取消 |
| 点击已建塔 → 出售 | 返还金币并恢复空坑位；点击空白处、右键或 Esc 关闭选项 |
| 点击底栏“防御塔 / 技能”或“收起” | 切换卡栏或收起操作栏 |
| 点击技能卡 | 火球再点击敌群选点；攻速强化立即生效 |
| 滚轮 / 右下角 +、− | 缩放地图，按钮逐档调整 |
| 左键拖图 / WASD / 方向键 | 移动视野 |
| Home / “全图”或“复位” | 查看全图或恢复视野 |
| 顶部“速度” | 循环切换 1×、2×、3× |
| Esc / 右上角菜单 | 暂停、继续、重开、返回选关或打开调试台 |

调试台可跳到指定波次，并补齐此前波次尚未获得的击杀金币，方便演示。暂停后继续保留所选速度，重开和换图恢复 1×。

## 运行

1. 在 Unity Hub 中添加仓库根目录，使用 **Unity 6000.3.27f1** 打开，等待资源导入。
2. 打开 `Assets/Scenes/MainMenu.unity`，点击 **Play**。
3. 点击“开始游戏”选择地图，拖卡建塔后手动开启第一波。

项目使用 URP 2D，编辑器运行统一从首页进入。详细说明见 [快速开始](Docs/GettingStarted.md)、[地图](Docs/MapsAndMenu.md)、[技能与演示](Docs/BattleItems.md)和[协作指南](Docs/GitHubCollaboration.md)。
